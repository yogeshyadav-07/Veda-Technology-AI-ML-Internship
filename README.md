# Student Marks Analysis

## Internship Task
**Organization:** Veda Technology  
**Track:** AI & ML  
**Task:** Student Marks Analysis

## Objective
Create a Python program to analyze student marks and calculate:
- Total marks
- Average marks
- Highest marks
- Lowest marks

## Approach
The marks are stored in a Python list. Python's built-in functions are used:
- `sum()` → calculates total marks
- `max()` → finds the highest mark
- `min()` → finds the lowest mark
- `len()` → finds the number of students

The average is calculated using:

`average = total_marks / number_of_students`

## Dataset
A manually created list of 10 student marks is used:

`[78, 85, 92, 67, 74, 88, 95, 81, 69, 90]`

## Output
- Number of students: 10
- Total marks: 819
- Average marks: 81.90
- Highest marks: 95
- Lowest marks: 67

## Interview Questions
1. How do you calculate the average of a list in Python?
   - Add all values using `sum()` and divide by the number of values using `len()`.

2. What is the difference between `max()` and `min()`?
   - `max()` returns the largest value, while `min()` returns the smallest value.

3. How can Python be used to analyze student data?
   - Python can store, process, calculate statistics, clean data, and later visualize student data using libraries such as Pandas and Matplotlib.
